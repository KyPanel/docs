# KyPanel documentation

The pages of [docs.kypanel.com](https://docs.kypanel.com), in Markdown.

- `content/`: one file per page; the top block holds the title and description
- `nav.json`: the sidebar order

## Fix or improve a page

Click **Edit this page on GitHub** at the bottom of any page on docs.kypanel.com, or edit the file here.
GitHub opens a pull request with your change; once it's accepted it goes live on the next docs update.

Keep the style of the existing pages: short sentences, menu paths written as Ky Admin › Section › Page,
commands and file names in `code`.

The API reference pages are generated from the panel's OpenAPI file and aren't in this repository.
